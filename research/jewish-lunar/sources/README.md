# Research snapshots

These are the existing research reports, copied unchanged for provenance. Their earlier
recording-only / weight-zero proposals predate the user's subsequent request for weighted
integration and explicit selection of 30% research / 70% baseline.

The current scoring specification is [INTEGRATION.he.md](../INTEGRATION.he.md), with the
source-to-rule map in [sources.json](../sources.json). Original source references remain in
each report. Some links to local PDFs/images refer to the original research workspace; those
binary source files are not duplicated into this repository. The reports themselves are not
newly executed experiments and must not be read as validation of the weighted overlay.
