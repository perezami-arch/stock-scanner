# שמירת המחקר במחשב Windows של אילן

לפי בקשת אילן, 10.10.2026, העותק המקומי המרכזי כולל מסמכי מחקר, מקורות, קוד, נתונים, גרפים ותחקורי עסקאות. החומר המקומי הקיים הועתק לתיקיית `סורק לשוק ההון` במחשב Windows. הנתיב המלא והאינדקס נמצאים בשיחה וב־`README.he.md` בתיקייה.

## מבנה

- `research/`: מסמכי גאן, ספר התכונה ומבוא השמש, המקורות הסרוקים, נתוני הירח והבדיקה ההיסטורית, כולל התוצאות שלא תמכו בהשערה.
- `code/`: קוד הסורק, שכבת המחקר, הבדיקות וכלי ההתקנה/הסנכרון.
- `inputs/`: התמונה ו־PDF הגרפים שהמשתמש צירף.
- `bot-data/`: קבצי הריצות והמעקב שמתקבלים מהבוט בלינוקס.
- `archives/`: חבילות נתונים שהורדו ורשימות התכולה שלהן.
- `.versions/`: גרסאות קודמות של קבצים מקומיים שהוחלפו.
- `local-inventory.json`: מלאי החומר המקומי וה־SHA256 של כל קובץ.
- `last-sync.json`: תוצאת ניסיון הסנכרון האחרון; מצב המתנה אינו גיבוי מוצלח של נתוני הבוט.

## מסלול הנתונים

1. בסיום ריצה שבועית או יומית הבוט מפעיל `--archive-data`. `publish_research_archive.py` אוסף את תיקיות המחקר המוגדרות בלבד: `scan-runs`, `news-cache`, `scanner-momentum-cache`, `openbb-snapshots`, `prompts` ולוח השנה הציבורי.
2. SQLite מועתק באמצעות מנגנון backup של SQLite, כולל עסקאות שהושלמו ביומן WAL. זה אינו העתק בינארי של מסד פתוח באמצע כתיבה.
3. תכולה חדשה נארזת לפי SHA256 ומצורפת ל־Release בריפו **הפרטי**. רק אחרי שכל החבילות והמניפסט הועלו, הטיוטה מתפרסמת. סיכומי המעקב ממשיכים להופיע גם כתיקיות בגיט.
4. Windows מוריד בעזרת `ops/sync_windows_research.py --destination PATH`. נדרש GitHub CLI המחובר לחשבון בעל גישה לריפו. ההורדה אינה דורשת SSH למחשב הבוט.
5. החבילות וכל קובץ בתוכן נבדקים מול גודל ו־SHA256. שמות נתיבים נבדקים כדי למנוע יציאה מהתיקייה. לא מורץ קוד מתוך החבילות. גרסה מקומית קודמת נשמרת; אין מחיקה של קובץ מקומי מפני שהוא נעלם אצל הבוט.

חבילות תוכנה מותקנות, תיקיות Git פנימיות, קובצי סביבה/מפתחות, קישורים ולוגים אינם נארזים. הנתונים, הקוד ומסמכי השחזור נשמרים. חבילה מעל כ־1.9 GiB נעצרת עם שגיאה במקום לדווח על העלאה שלא בוצעה. אין מחיקה אוטומטית של ארכיונים.

## הפעלה במחשב הבוט

להתקין את עדכון הקוד ואת קובצי השירות החדשים לפי [התקנת לינוקס](LINUX_DEPLOYMENT.he.md). GitHub CLI של הבוט צריך להיות מחובר לריפו הפרטי עם הרשאת כתיבה ל־Releases. לא משנים את נראות הריפו.

```bash
python3 /workspace/run_scheduled.py weekly --archive-data
python3 /workspace/run_scheduled.py daily --archive-data --publish-progress
```

לשליחת החומר הקיים בלי להריץ סריקה חדשה:

```bash
python3 /workspace/publish_research_archive.py
```

עד שהבוט מפעיל זאת, סנכרון Windows מדווח `waiting_for_linux_archive`. ההעתקה המקומית של המחקר הקיים כבר נעשתה; נתונים שטרם התקבלו מלינוקס אינם מוצגים כקבצים מגובים.

מפרט תזמון Windows: המעקב היומי הקיים בשיחת Codex, ב־10:30 שעון ירושלים, מבצע הורדה ואימות לפני תחקור התוצאות. זמינותו תלויה במחשב ובסביבת Codex; ניתן להריץ את סקריפט ההורדה ידנית באותה תיקייה.
